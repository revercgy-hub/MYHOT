# 财政金融精选规则

## 行业类型

结构化 `itemType` 固定为：

`policy_release`、`regulatory_rule`、`fiscal_data`、`financial_data`、`debt_event`、`regulatory_action`、`local_practice`、`research_analysis`。

缺失分类标签时的映射为：

| 内容类型 | 分类标签 |
|---|---|
| `policy_release` | 政策发布 |
| `regulatory_rule` | 制度规则 |
| `fiscal_data` | 财政数据 |
| `financial_data` | 金融数据 |
| `debt_event` | 政府债务 |
| `regulatory_action` | 监管处罚 |
| `local_practice` | 地方实践 |
| `research_analysis` | 研究报告 |

一篇资料的第一个标签必须是分类标签；主题标签和机构标签只能从 `industry/taxonomy.ts` 白名单中选择。没有实质对应主题时不补标签。标题、摘要和事实不得添加原文未出现、且发布方无法明确证明的机构。

## 门槛

保留上游初始值：T1 60、T1.5 65、T2 76；`understandFloor` 保留当前行业包原值。两次独立评分的平均达到信源档位门槛后入选。任务书说明该数值来自上游 AI 行业校准，只作为财政金融版的初始测试参数，尚未用本行业 Gold Dataset 正式校准。不得凭主观判断调门槛。

预筛宽召回财政政策、预算、政府债务与专项债、财政金融协同、金融运行、金融监管与风险、财会监督，以及福建厦门地方实践。明确无关的市场行情、产品营销、党建招聘培训和无新增事实的宣传内容可过滤；官方身份本身不构成入选理由。

## 重大民生政策与央行日常公告（2026-10-24用户确认）

站点分类新增第九类“重大民生政策”；结构化 `itemType` 仍为上述八种，不因栏目扩充而新增类型。用户确认的范围是：“国家级重大民生政策也纳入，即使没有明确财政金融安排”。筛选时仍根据政策本身的重要性和实质内容判断，不能只凭发布机构身份、一般科普或地方活动归类。

用户还确认：“央行日常公告放在全部动态，出现重要操作或政策变化时才精选”。因此日常公告属于宽召回展示范围，不应仅因属于央行公告而自动精选；是否精选仍按当前冻结的双轮评分与60/65/76门槛判断，不能把“重要”另行硬编码为未经校准的新阈值。

## 校准

### 当前重点业务（2026-10-30用户确认）

用户明确：“直接属于财政金融监管业务，就应优先评估精选”，理由是相关工作是当前重点。以财政贴息、创业担保贷款、普惠金融政策落实、金融企业财务监管及金融风险识别、监测、处置为实质主线的具体业务稿，优先评估其直接工作用途；没有金额、处理结果或可复用的新方法，不构成机械排除理由。工作介绍、总结或经验稿的形式本身也不构成降分理由。

这不是自动精选：正文事实仍分别支持五轴，避免同一相关性理由在影响、信息增量等维度重复计分。一般预算、转移支付、会计师事务所执业检查、国有资本收益审核及银行服务网点推广，不因机构名称、监管字样或金额自动享有该优先级；重要制度变化、风险事实或处置结果仍正常评估。用户对九篇具体材料的原有选择不变，无需重复确认同一原则。

完整development评估完成后才能讨论校准结果；开发候选五轴结构输出尚未替换正式评分。旧holdout已参与查看，后续正式独立验收须使用未参与调优、按事件隔离的新样本。现有八类、五轴权重和60/65/76门槛保持不变。

从本行业实际资料建立 `.data/gold.jsonl`，至少包含重要政策、一般政务稿、地方实践、债务、监管处罚、财政金融数据和宣传噪声。分别检查查准率、查全率及各类错例，再决定是否调整评分文字或门槛。Gold 数据不得提交 Git。

常规开发和自动运行仍保持`MODEL_CALLS_ENABLED=false`；另有显式有界的本地模型开发评估，经独立预算、回执及输入冻结约束运行，不等于开启自动精选或公开发布。
