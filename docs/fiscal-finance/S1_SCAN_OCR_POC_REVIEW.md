## 裁定和依据

批准 Luna 在 Gate 2 尚未通过时开展一次固定输入的本地 OCR 开发实验。依据 [AGENTS.md](../../AGENTS.md)、[PROJECT_PLAN.md](PROJECT_PLAN.md)、[STATUS.md](STATUS.md)、[阶段依赖 S1](ARCHITECTURE_PHASE_DEPENDENCIES.md)、[扫描路线提案](P3_SCAN_BODY_PROPOSAL.md)、[核心正文缺口处置](P3_CORE_BODY_RESOLUTION.md)、[福建人工独立复核](P3_FUJIAN_TRANSCRIPTION_REVIEW.md)、[厦门人工独立复核](P3_XIAMEN_MANUAL_REVIEW.md)及[本轮核心批次](P3_CORE_BATCH_2026-09-30.md)。

产品需要持续自动获取核心财政公告；逐份人工转录只适合样本证据，不能满足长期产品目标。已知两份官方附件有完整人工 gold、扫描正文机器失败且没有已核实的同公告可读替代，因此用现有 Tesseract 验证机器候选路线是必要且有限的下一步。此实验不进入 P4、不调用仓库模型服务，不违反“核心源稳定后才启用模型”的阶段约束。

本裁定仅为此前 S1 所要求的另行 OCR 范围审查补充一次固定样本实验授权，不撤销其通用能力和阶段边界。OCR 不升级为所有来源的 Gate 2 硬前置。福建、厦门这两类核心业务附件若要进入实际自动处理范围，仍须解决机器正文完整性；实验成功也不能把整体来源验收写成通过。

## 批准的最小输入与产物

- 复用既有五张 PNG：福建 `.data/fiscal-central-audit/rendered/fujian-{1,2,3,4}.png`，厦门 `.data/fiscal-qa/xiamen-debt-round16-page.png`。运行前对照两份人工复核报告校验每张图 SHA-256，页序固定为福建 1–4、厦门 1。不重取官网 PDF、不重新渲染、不扩大样本；哈希不同、缺页或损坏立即停止并报告。
- 使用已安装 Tesseract `5.5.0.20241111`，记录可执行文件路径、版本和 hash。提案记载当前仅有 `eng`、`osd`，未装 `chi_sim`，本审查没有重新执行安装检查。允许取得一份官方简体中文 `chi_sim.traineddata`，以 `chi_sim+eng` 或 `chi_sim` 运行；明确记录语言、OEM、PSM及参数，不用 OSD 自动猜页序。
- 只写一个专用 ignored 实验目录，例如 `.data/fiscal-qa/scan-ocr-poc/`：语言文件、许可证、输入 manifest、一次性脚本、逐页原始文本/TSV、candidate 字段、gold 对照和运行日志。可新增一份 tracked 结果报告；大型二进制、原图、机器输出、脚本不进入 Git。不修改 `apps/`、`packages/`、schema、依赖锁文件或来源配置。
- 不接 collector、worker、正文 helper、数据库、队列、publication 或公开预览。所有采集、模型、Jina、IndexNow、Feishu、私网抓取开关保持 false；source 继续 disabled/fulltext false。OCR候选没有 `body_status=ok` 写入路径，也不生成 analyze jobs。

## 一次性语言文件获取边界

离线实验有一个显式联网准备步骤：仅取得官方 Tesseract 数据仓库的固定版本简体中文文件与适用许可证。优先官方 `tesseract-ocr/tessdata_fast`；运行前记录完整 commit SHA 或可核验的固定 release，以及最终对应的完整 commit，使用该不可变版本的精确文件 URL。不得使用 `main`、`latest`、第三方镜像、运行时自动下载或整库 clone。

准备步骤最多 3 个实际 HTTP 请求、无重试、无自动重定向：若需要，1 次官方版本定位，1 次语言文件、1 次许可证。每请求墙钟 deadline 30 秒；语言文件最多 32 MiB，许可证/版本元数据每项最多 1 MiB；超过即终止、不接着尝试替代仓库。保存来源 URL、commit、取得时间、实际字节数、文件 SHA-256、许可证名称与原文。无法证明官方来源、版本或许可证则不运行 OCR。首次取得后的 SHA-256 是本地固定身份与复跑依据，不把它声称为上游签名验证。

下载执行器应使用明确不跟随重定向的请求路径，并在实际请求发出入口计数和拒绝超额；先以本地假响应/静态检查核实其阻断。禁止复用本轮两批已失效的 Undici dispatch hook 或把顶层函数调用数当作 HTTP hop 数。这个一次性获取边界不授权重抓业务网站或建设通用联网框架。数据取得后 OCR 子进程不含网络调用；这是执行范围控制，不声称构成 OS 网络沙箱。

## 进程、输出和资源上限

采用独立 CLI 子进程，参数数组传递文件路径，串行处理、并发 1、`OMP_THREAD_LIMIT=1`。只做一次基线运行：每页一次、共 5 次；固定引擎和模式，无无限参数搜索、无失败自动重跑。若结果显示需比较另一布局模式，由 Lead 另定有限第二轮，不自动消耗额外轮次。

| 边界 | 本次上限和处置 |
|---|---|
| 输入 | 仅固定 5 页；单页不超过 25 百万像素、20 MiB，五页总输入不超过 100 MiB；运行前检查，不为适配上限静默重采样 |
| OCR 时间 | 每页 30 秒；5页实验总墙钟 180 秒；超限实际终止子进程/进程树并等待退出，不能只让调用者返回 |
| 输出 | 每页文本+TSV+stderr累计最多 1 MiB，全部运行最多 5 MiB；文本全样本最多 120,000 字符；对文件输出也实施监测，不能只限制 stdout |
| 资源 | 单进程工作集监测停止线 512 MiB，采样间隔不超过 250 ms；超过即终止；记录峰值、采样方法和 kill/exit 结果。若用 Windows Job Object 硬上限，记录实际设置与核验；普通采样线须明确写成可能瞬时越界的软停止线，不能声称硬 RSS |
| 实验目录 | 输出产物最多 10 MiB（固定输入引用和语言文件除外），不得将临时文件散落其他目录；保留必要诊断及失败原因 |

不得以 Node/V8 heap flag 代替 Tesseract 原生进程内存限额。这里批准的是受控本地实验的有界执行和如实测量，不要求提前实现 NAS 容器隔离、Linux 集成或通用进程管理库。若当前五页图超过输入边界，或本机无法可靠终止/观测该原生进程，先停止并由 Lead 裁定最小修正；不能取消上限继续。上线所需硬 RSS、部署隔离和恢复仍按既有阶段 S1 处理。

## candidate 与 gold 核验要求

运行前从已经双核接受的人工报告固定 gold manifest，保留报告、版本、页号和输入图像 hash。gold 不从 OCR 输出反向修改。原始文本/TSV保留，字段拆分只产生 candidate；未知、遗漏、错位和歧义明确记为 missing/ambiguous/mismatch，不从 gold 补值伪装成机器命中。

福建必须覆盖四页：机构、文号、标题、日期、23行序号/中标机构/存款额/利率/预计利息、两项合计、规模、期限、起息/到期日及页3定价说明、落款与页4公开/印发信息。同名第21与23行保留为独立行，不能按名称去重。对23行金额/利率逐字段比对并核查两项合计；采用十进制金额计算，只将既有一月期算术检查作为本样本一致性检查，不外推通用计息规则。

厦门必须逐项比对人工复核表全部14个字段，包括发布机构、标题/期次、招标/签章日期、债券编码、计划/实际发行规模及单位、7年（5+2年，含权）、1.55%、100元、12月/次、付息日及两种到期日。保留日期条件文字和单位，不用数字相同抵消“亿元/元”或含权条件缺失。两样本的印章细字与二维码继续 unknown；OCR猜测不使其成为已核实事实。

报告区分原始识别、显式归一化和布局/字段抽取。可归一空白、全半角字符与千分位，但逐项记录规则；不得补数字、小数点、百分号、日期、条件文字或银行名称。给出每字段 expected/candidate/页号/判定与差异，各页完整性、表格行列错位、置信度局限、运行时延/峰值和超限结果。不能以总体字符准确率、高置信度或合计相等掩盖错行/错字段。

所有页完成且核心字段全匹配时，可记 `fixed_sample_ocr=matched`，仍只是两份固定样本的候选准确性证据。任何关键字段不匹配则记 partial/failed，并保留负例。任何结果都不自动标 body ok、不启用来源、不进入模型或发布。两样本不是留出集，不能据此宣称跨期泛化、自动来源稳定或长期免人工维护已经成立。

## 新批次事实及后续边界

核心批次的实际 HTTP hop 数 unknown，失效 hook 不满足可证预算；本 S1 不追认 budget PASS。预算司首轮只导入1篇，第二轮导入9篇旧文是实际 collector 首导入/普通轮次差异，不能借 OCR 实验修复或忽略。核心批次6篇 unconfirmed 的原因没有现有接口证据，不可断言均为扫描件或网络故障。区域批次相同计数故障也不能借本实验追认。上述问题继续由对应来源/批次负责人记录和处置。

实验结束后 Lead 先评估字段差异及执行边界是否满足。可靠性不足应保留失败并决定是否有限调整；即使两样本匹配，进入 backend、正文状态/审阅持久化、自动运行和部署前仍须另做有证据的最小实施 S1。当前不建设通用 OCR系统，也不在缺完整 Gate 2证据时重复做 Gate 2审查。真实 PDF Linux 验证与 NAS 资源验收仍属于此前 S1规定的阶段。
