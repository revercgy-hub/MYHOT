## 排序结论

**正式 Gate 2 的真正阻塞**是：尚无足以判断首页候选能否覆盖真实轮询间隔、突发发布及失败恢复的跨周期证据；几项核心内容存在已知机器正文缺口/假阳性或尚未解释的 `unconfirmed`；区域批次有5篇短正文待判。两次完整首页批次的历史 HTTP hop 总量未知，这一历史事实不能追认预算通过，但它本身不永久阻挡 Gate 2，也不要求重跑原批次；未来用于验收的有界新批次可用本身经验证的计数/硬停止证据替代其预算证据。先用有硬上限、可复核的少量官方 GET 补最有价值的可读正文与地方监管动态证据，再按已有证据决定剩余小批次；每次只回答一个明确问题。

明确的正文反例（特别是厦门债券招标结果的205字假阳性）必须有保守的排除/失败记录，才能把该样本从Gate 2正文验收清单中结清；这不要求在Gate 2先实现通用PDF/OCR。会计司9/4固定详情单次请求结果仍是`unconfirmed`且reason `UNKNOWN`，未保存原HTML；不追认原因，也不重试。Root另核销的7/15保存列表候选详情已单次观察为HTTP 200、`unconfirmed`，结构化reason `attachments_unprocessed`，正文0字、无hash。此结果只结清该次调用的失败分类，不证明附件正文可读或该源通过；未请求附件、无重试。

**可后置且不是Gate 2通用前置：**通用自动分页、所有历史页覆盖、NAS部署/RSS硬限制/连续运行、真实官方PDF的Linux集成（最迟P7/Gate4验证）。OCR不是Gate 2通用前置；扫描PDF如果作为某源必须持续机器自动获取的核心正文，则该特定正文路径需另有验收，否则明确记为不支持/未确认，不以人工转录宣称机器通过。训练文件已有可运行准备清单，不表示Tesseract已运行、OCR已验证，更不授权worker或collector集成。

财政部“各地监管局动态”配置是财政部官网选登汇总入口。当前首页8条、相邻页样本以及35个域名allowlist均不能证明收齐35个局的全部动态；厦门监管局独立栏目只是单一地方代表源。按“汇总栏目覆盖”描述，不得称“全国35局full coverage”。本段是撰写时的范围判断；2026-10-03用户已明确要求首阶段逐局覆盖。该决定不回写为过去已有覆盖证据，当前逐局覆盖矩阵和行动要求见本报告前置增量。

## 下一批可核销的小预算官方URL计划（当前只提案）

目的限定为：验证地方监管新闻正文在当前机器提取路径下是否可读、标题/列表日期是否对齐，并为HTTP dispatch预算工具提供一份可核验的新样本。优先顺序：

3. 若前两条均无需新GET，从厦门监管局“监管工作”当前列表挑一条此前未访问的业务新闻；URL必须先从保存列表快照中读出，不能猜路径。
4. 如果该次确要新GET，再用财政部中央选登汇总中一条不同地方局、此前未访问且保存候选可确定的详情URL替代同类重复项；保留其“官网选登”归属，不宣称全量覆盖。

拟议预算上限为**最多4次真实Undici dispatch：1次列表 + 最多3次精确详情**，超限在dispatch前拒绝；重定向每一跳计作一次dispatch，默认`redirect=0`，不重试、不跟随未授权附件、不启动collector/worker/模型、不写现有或隔离数据库。若URL既有缓存已经回答问题则取消对应GET，空余额度不自动转给别的源。每次请求保存精确URL、时间、状态码、请求事件、redirect数、正文长度/hash、列表与详情对照、失败/拒绝reason；若工具不能做到这些，先改离线证据采集器并本地验证，不能把计划预算当实际观测。

同一批次不承担跨周期结论。另需至少两个有时间间隔的只读列表观测，并预先记录源轮询间隔（配置当前一般120分钟、两条监管局源360分钟）、快照时间、首页最旧候选、候选集合新增/退出；没有覆盖正常间隔及合理中断/突发的观测，Gate 2只能继续待定。有限小预算与跨周期监测可拆批核销，不一次扩大预算。
