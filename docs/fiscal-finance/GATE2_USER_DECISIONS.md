## 已确认的六项产品决定（不代表实现或Gate通过）

1. **逐局覆盖**：首阶段覆盖全国财政部地方监管局新闻动态栏目；中央选登只作补充。35个目录仍待逐局栏目与质量核实。
2. **内容边界**：无实质业务事实的内部活动排除；新政策、问题发现、监管措施、调研成果纳入；地方一手不因传播范围而降低优先级。prefilter/selection prompt已更新措辞，实际模型效果与硬过滤未验证。
3. **无法解析的业务附件**：保留原始URL，标正文待解析，不自动精选，后续补能力；不支持不等于正文ok或Gate通过。自动路径尚未实现，待S1最小范围裁定。
4. **检查频率**：所有来源每日检查一次；未指定具体时刻、失败重试/恢复策略。12条行业source JSON目标已设1440分钟，但仍disabled且未导入数据库，schedule未运行。
5. **首次回填**：上线时取近90天；历史稿按原发布日期呈现，不冒充当天新稿；不删现有数据库数据。12条行业source JSON已设3个月（30天/月，带发布日期候选约90天），但仍disabled、未导入数据库；无日期候选仍可能通过筛选，严格边界待S1。
6. **浙江首期栏目**：先以“监管工作”作为主栏目入口，“图片新闻”留作后续补充。两个栏目的已存证据分别记录；此决定不宣称栏目等价、完整覆盖或source pass。

## 决策处理规则

- 每次仅在上一个问题有明确答复或Root决定暂缓后，再由Root提出下一项；回复前保持`UNKNOWN`，不填写推定默认。
- 用户决策改变的是产品范围/验收解释；它不改写既有抓取事实、来源边界、安全策略或Gate 2正式审查权限。
- 技术证据可以回答工程问题，但不能回答用户要覆盖哪些机构、什么内容值得读、正文失败是否可接受、读者期望时效或初始历史深度。
- 问题1已确认逐局覆盖：财政部中央选登汇总仍只能按汇总栏目描述，不替代地方局新闻动态栏目；后续应逐一列出实际入口和验证状态，不能仅因allowlist列有35个域名即声称完成。
